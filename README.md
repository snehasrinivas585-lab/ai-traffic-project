🚦 AI Traffic Flow Optimizer
📌 Overview

This project is an AI-based traffic management system designed to reduce congestion by optimizing traffic signal timings. It uses data analysis and machine learning techniques to predict traffic conditions and improve overall traffic flow.

⚙️ Features
🚦 Dynamic traffic signal timing
📊 Traffic congestion prediction (High / Medium / Low)
🤖 Machine learning-based analysis
🌐 Flask web interface for user interaction

🛠️ Tech Stack
Python
Flask
Machine Learning (KMeans, Linear Regression, Decision Tree)
Pandas, NumPy, Matplotlib

🚀 How to Run
Clone the repository
Navigate to the project folder
Run the application:
py notebooks/app.py
Open your browser and go to:
http://127.0.0.1:5000/

📊 Output

The system analyzes traffic conditions based on user input and provides:

🚨 Traffic level prediction (High / Medium / Low)
🚦 Optimized signal timing for each lane
📈 Visualization of traffic patterns using machine learning models
