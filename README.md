# 🚦 AI Traffic Flow Optimizer

## 📌 Overview
This project aims to optimize traffic signal timing using algorithmic techniques to reduce congestion and improve traffic flow efficiency.

---

## ⚙️ Features
- Dynamic traffic signal timing
- Congestion analysis
- Graph-based route optimization
- Efficient path calculation using algorithms

---

## 🛠️ Tech Stack
- Python
- Graph Algorithms (Dijkstra)
- Data Structures

---

## 🚀 How to Run
1. Clone the repository:
   git clone https://github.com/snehasrinivas585-lab/ai-traffic-project

2. Navigate to the project folder:
   cd ai-traffic-project

3. Run the program:
   python main.py
